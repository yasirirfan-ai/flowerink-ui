FLOWER INK LOCAL PREVIEW

Start from this folder:
  npm run dev

Open:
  http://localhost:8080

Node.js 18 or newer is required. No npm install is needed.
Keep index.html, the CSS/JS files, img, package.json, and scripts together.
Ctrl+C stops the preview server; it does not remove project files.
